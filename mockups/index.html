Worth checking specifically
Things I changed that you should eyeball
1. Tab with the keyboard anywhere — buttons and chips now show a focus ring. v2 had none.
2. Login page, let the browser autofill — Chrome used to repaint those inputs white.
3. Library, press Upload — watch the sheen sweep across the progress bar.
4. Feed, tap a filter chip — the card list re-runs its staggered entrance. If that flicker bothers you, it's five lines in §3 of the v3.1 layer.
5. Community on a phone — the composer should stay put as the URL bar collapses.
6. Admin, drag the users table sideways — it no longer drags the page with it.
7. Any toast — it should no longer block taps at the bottom of the screen while invisible.
8. Turn on "reduce motion" in your OS — everything should go still, nothing stuck invisible.
Not included
These are presentation mockups. There is no auth, no Supabase call, no real upload, and no moderation — mock.js only toggles CSS classes so the states are visible. Nothing here should be copied into the app as-is.
